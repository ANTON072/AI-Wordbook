# run-steering

ステアリングディレクトリを指定して、`plan.md` と `tasklist.md` を読み込み、未完了の最初のタスクから作業を再開する。

## 手順

### 1. ディレクトリを特定する

引数が渡された場合：`docs/steering/` 配下のディレクトリ名を引数で部分一致検索する。

```bash
ls docs/steering/
```

- 一致が1件 → そのディレクトリを使う
- 一致が複数 → 候補を列挙してユーザーに選択を促す
- 一致なし → 一覧を表示して「どれですか？」と聞く

引数が省略された場合：一覧を表示して選択を促す。

### 2. plan.md と tasklist.md を読む

特定したディレクトリの両ファイルを Read する。

```
docs/steering/<dir>/plan.md
docs/steering/<dir>/tasklist.md
```

### 3. 未完了の最初のタスクを見つける

`tasklist.md` の中から `- [ ]` で始まる最初の行を探す。すべて `- [x]` であれば「このステアリングはすべて完了しています」と報告して終了する。

### 4. 作業を開始する

見つかったタスクの内容を実行する。

**`[HUMAN]` タスクの場合：** 作業を止め、ユーザーに実施すべき操作を説明して完了報告を待つ。完了報告を受けたら該当行を `- [x]` にして次のタスクへ進む。

**Claude が実施するタスクの場合：** そのまま作業を進める。タスクが完了したら `tasklist.md` の該当行を `- [x]` にチェックし、進捗状況セクションを更新してから次のタスクへ進む。

### 5. 進捗状況を更新する

`tasklist.md` の「進捗状況」セクションに日付と完了したタスクの概要を追記する。

---

## ルール

- plan.md の設計・制約事項は作業の判断基準として参照する。実装に迷ったら plan.md に戻る
- tasklist.md のチェック状態が唯一の進捗情報源。完了したらすぐに `- [x]` にする
- セッションをまたぐ場合、次回は同じ `/run-steering <dir>` で再開できる
