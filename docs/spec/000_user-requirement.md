# AI-Wordbook

- mcpを自分で作ってみたい個人的プロジェクト
- Claudアプリから「reliableをwordbookに登録して」と投げると単語帳に単語と和訳と品詞と例文（3つほど）が登録される
- Web画面から登録した単語の一覧をチェックできる
- 管理画面はつくらない。代わりにClaudeアプリからmcp経由で操作が可能とする。
- ログイン必須。ユーザーごとに単語帳が作られるイメージ。ただしユーザーは管理者がユーザーを作って配布する形式とする。自由登録不可。

## 本フェーズでは扱わないこと

- 単語と例文の音声読み上げ

## 利用したい技術スタック

- TypeScript
- AWS & SST
- 認証はAmazon Cognito
- Next.js
- OpenAI API（次フェース以降で音声読み上げ機能を検討しているから）
