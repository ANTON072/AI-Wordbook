## 2026-07-31 lib/ 単体テストと MCP ツール結合テストの役割分担

**決定：** `src/lib/normalize.test.ts` / `src/lib/schema.test.ts` の純関数単体テストは保持する。

**次フェーズへの制約：** MCP ツールの結合テストを書く際、正規化・バリデーションの同ケースを結合テスト側で**再アサートしない**。結合テスト側はハッピーパス＋代表的な異常系1〜2件に留め、境界値の網羅は `lib/` 単体テストに委ねる。
